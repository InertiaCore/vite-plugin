## Introduction

> [!IMPORTANT]
> This plugin is a fork of the [Laravel Vite plugin](https://github.com/laravel/vite-plugin), but with out of the box support for [InertiaCore](https://inertiacore.net).

[Vite](https://vitejs.dev) is a modern frontend build tool that provides an extremely fast development environment and bundles your code for production.

This plugin configures Vite for use with a ASP.NET InertiaCore backend server.
